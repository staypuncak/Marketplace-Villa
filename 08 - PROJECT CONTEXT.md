# Project Context

**Project:** StayPuncak.com

**Version:** 1.0.0

---

# Executive Summary

StayPuncak adalah platform digital penyewaan villa di Puncak Bogor yang dibangun menggunakan EZOS Alpha v1.0.

Project berfokus pada pembangunan aset digital yang mampu menghasilkan lead secara organik melalui SEO dan mempermudah proses booking melalui WhatsApp.

# Key Decisions

- Booking menggunakan WhatsApp.
    
- Dashboard hanya untuk Admin pada MVP.
    
- Database mendukung Multi Owner sejak awal.
    
- Architecture bersifat Future Ready.
    
- SEO menjadi strategi pertumbuhan utama.
