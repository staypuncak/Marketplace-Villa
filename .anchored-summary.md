# StayPuncak — Project Summary

## Tujuan
Marketplace villa premium Puncak dengan admin dashboard, auth Supabase, dan CMS villa full CRUD.

## Tech Stack
Next.js 16.2.9 · TypeScript · Tailwind v4 · App Router · Supabase (auth, DB, storage) · shadcn/ui

## Fitur Publik
- **Hero** — 3 MP4 video background crossfade 8 detik, headline emosional, gold accent
- **SearchCard** — floating card antara hero & grid, filter lokasi/kapasitas/urutan harga, reset "Semua Villa"
- **VillaCard** — premium card: hover zoom, rating, specs, price hierarchy, CTA
- **Detail Villa** — gallery (5 SVG placeholder), overview, suitability (4 cards), booking WhatsApp, sticky CTA
- **Blog** — 5 artikel statis, featured + 3-col grid
- **Footer** — Dark Forest Gradient, brand/nav/kontak/social
- **WhatsApp Float** — sticky bottom-right, desktop hover-expand, IntersectionObserver footer-aware

## Dashboard
- Route group `(public)` separation, root layout minimal
- **Auth** — Supabase + `admins` table, SECURITY DEFINER RPC bypass RLS (`check_admin_by_email`, `link_admin_auth`)
- **Home** — KPI cards, Quick Actions, Website Status
- **Villa CMS** — card list + 5-step wizard (`VillaForm` shared component)
  - Step 1: Informasi Dasar (nama, slug, lokasi, harga, kapasitas, status)
  - Step 2: Media (thumbnail, hero, gallery — upload ke Supabase Storage bucket `villa-media`)
  - Step 3: Fitur Utama + Fasilitas Tambahan (chips + custom add/remove)
  - Step 4: Booking (check-in/out, minimum stay, catatan)
  - Step 5: SEO & Publish (SEO title, meta description, OG image)
  - Create → `insert()`, Edit (via `/dashboard/villa/[id]/edit`) → `update()` + re-insert media

## Database
- Tabel `villas` — semua kolom CMS sudah ada (12 kolom tambahan via migration `add_villa_cms_fields`)
- Tabel `media` — path storage, no binary/base64
- Seed: 5 villa + 5 media records
- RLS: `is_admin()` function, SECURITY DEFINER RPCs untuk admin lookup
